# Shri Balaji Enterprise - DSA Management System

A cloud-connected management system for tracking loan applications, payouts, and executive performance.

## 🚀 How to Host this App (GitHub Pages)

To get your app live on the internet so you and your team can access it anywhere:

1.  **Install GitHub Desktop**: Download it from [desktop.github.com](https://desktop.github.com/).
2.  **Add this folder**:
    *   Open GitHub Desktop.
    *   Go to **File > Add Local Repository**.
    *   Select this folder: `c:\Users\WHIGHT PC\Desktop\SBE web`.
    *   Click **Publish Repository** and name it `sbe-management`.
3.  **Turn on the Website**:
    *   Go to your new repository on [github.com](https://github.com/).
    *   Click **Settings** (top tab).
    *   Click **Pages** (on the left menu).
    *   Under **Build and deployment > Branch**, select `main` and click **Save**.
4.  **View your app**: In a few minutes, your site will be live at `https://yourusername.github.io/sbe-management/`!

## ✨ Features
- **Cloud Sync**: Powered by Firebase Firestore. Data is saved in real-time.
- **Owner Dashboard**: Track total disbursed files and executive performance.
- **Excel Support**: Import and Export data directly to Excel/CSV.
- **Mobile Friendly**: Responsive design for use on any device.
